# Сайт про олимпиады по математике

Привет! Это мой учебный проект — сайт, который помогает школьникам 
5–11 классов готовиться к олимпиадам по математике.

## Зачем он нужен

Многие ребята хотят участвовать в олимпиадах, но не знают с чего начать: 
где регистрироваться, когда дедлайны, какие олимпиады вообще есть. 
Я собрал всё это в одном месте, чтобы было проще.

## Что внутри

- Главная страница с ближайшими олимпиадами по математике
- Отдельные страницы для каждого класса с 5 по 11
- Календарь с датами олимпиад и экзаменов
- Блок с советами, как готовиться
- Форма подписки на новости
- Адаптив — сайт нормально выглядит и на телефоне, и на компьютере

## Из чего сделан

- HTML — разметка страниц
- CSS — стили, анимации, адаптив (Flexbox, Grid, медиа-запросы)
- Хостинг — GitHub Pages

## Как посмотреть

Просто открой файл `index.html` в браузере. Или зайди на сайт 
по ссылке GitHub Pages (она в настройках репозитория, вкладка Pages).

## Структура файлов

- `index.html` — главная
- `style.css` — все стили
- `pages/` — страницы для 5–11 классов
